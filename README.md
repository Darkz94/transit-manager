# Transit Manager

An original, offline-first transport company management game built with Godot. The full-map goal is South Africa, with local deliveries, line hauls, and long-haul contracts.

The first release target is Android phones and tablets in landscape orientation. PC builds are outside the current scope. The research snapshot and staged development plan are in [docs/ROADMAP.md](docs/ROADMAP.md). Stage 0 decisions, map prototype, offline simulation, the first freight and long-haul loops, and the first maintenance system are documented in [docs/STAGE_0_FOUNDATION.md](docs/STAGE_0_FOUNDATION.md), [docs/STAGE_1_MAP.md](docs/STAGE_1_MAP.md), [docs/STAGE_2_SIMULATION.md](docs/STAGE_2_SIMULATION.md), [docs/STAGE_3_LOGISTICS.md](docs/STAGE_3_LOGISTICS.md), [docs/STAGE_4_CONTRACTS.md](docs/STAGE_4_CONTRACTS.md), and [docs/STAGE_5_FLEET.md](docs/STAGE_5_FLEET.md).

The project uses Truck Manager - 2027 as a reference for management-simulation feature categories. Transit Manager will use original branding, maps, vehicle designs, interface, text, and game balance.
